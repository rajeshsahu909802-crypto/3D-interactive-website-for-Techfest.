# Techfest 26

An interactive 3D festival landing page built with Vite, vanilla JavaScript, and Three.js.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:5173/`.

## Included

- Full-bleed Three.js orbital sculpture with rings, particles, lighting, and grid floor
- Pointer-reactive scene movement and scroll-linked camera motion
- Scroll narrative with signal, program, and visit sections
- Responsive desktop/mobile layout with no horizontal overflow
- Interactive program frequency cards
- Production build via `npm run build`
